## 0. 一句话目标

实现 `bwtsearch`:对**行程编码后的 BWT**(`.rbwt`)文件,用 **BWT backward search**
找出搜索串的**所有出现**(含重叠),每个匹配打印 `前≤2字符 + 匹配串 + 后≤2字符`。

## 1. 数据是怎么来的(理解管线)

```
原始 DNA (.txt)  ──BWT──▶  BWT 序列 (.bwt)  ──RLE──▶  行程编码 (.rbwt)  ← 只给这个
   ACTG...ACGT\n            ATGCT...CCCCCC              一堆字节
```

- 字符集只有 5 个:`\n A C G T`(注意 `\n` 也是字符,参与排序)。
- ASCII 排序:`\n`(10) < `A`(65) < `C`(67) < `G`(71) < `T`(84)。
  → FM-index 的 `C[]` 表就按这个顺序算。

### RLE 字节格式(必须先吃透)

一个字节 = `[3 位字符][5 位行程长度]`,**行程长度 = 存储值 + 1**。

| 字符 | 3 位码 |
|---|---|
| A | 000 |
| C | 001 |
| G | 010 |
| T | 011 |
| \n | 100 |

- 存 0 → 1 个,存 31 → 32 个。超过 32 的行程拆成多个字节。
- 解码:`ch = byte >> 5; len = (byte & 0x1F) + 1;`

## 2. BWT backward search 核心(算法骨架)

FM-index 三件套:

| 记号 | 含义 | 怎么来 |
|---|---|---|
| `C[c]` | 全 BWT 里**严格小于字符 c** 的字符总数 | 统计各字符总频次后前缀和 |
| `Occ(c, i)` | BWT 前 `i` 个字符里 c 出现的次数(rank) | 需要能对任意位置快速求 rank |
| BWT 本身 | L 列(last column) | 从 `.rbwt` 解码/按需重建 |

### backward search(找出现区间 [sp, ep])

```
c = pattern[last]                       // 从模式串最后一个字符开始
sp = C[c] + 1
ep = C[c+1]                             // 或 C[下一个字符]，闭区间写法看实现
for i = len-2 down to 0:
    c = pattern[i]
    sp = C[c] + Occ(c, sp-1) + 1
    ep = C[c] + Occ(c, ep)
    if sp > ep: 无匹配, 返回
匹配次数 = ep - sp + 1                   // 这就是出现数
```

- 区间 `[sp, ep]` 里的每一行,都对应**排序后后缀矩阵**里以 pattern 开头的一行。
- 行数 = 匹配数(题目保证 ≤ 5000,所以匹配数很小,好办)。

### 从区间还原「上下文」(前 2 / 后 2 字符)—— 本题真正麻烦的地方

匹配到的是**在 BWT 里的行号**,要输出原文上下文,需要能:

1. **向前扫**(LF-mapping):`LF(i) = C[L[i]] + Occ(L[i], i)`,反复走能拿到匹配**前面**的字符。
2. **向后扫**:需要 `\psi` 或用 SA(后缀数组)/采样把行号映射回原文位置,再取匹配**后面**的字符。

> 只需要前后各 2 个字符,而且匹配数 ≤ 5000,所以**不必**建整段原文——
> 对每个匹配行做几步 LF/ψ 即可。关键在别把整个 SA 存进内存(会爆 16MB)。

## 3. 最容易踩的三个坑

### 3.1 内存 < 16MB(最硬的约束)
- 文件可达 **110MB**,**绝对不能**把解码后的整段 BWT 明文塞进内存。
- 要么**保持 RLE 压缩态 + 采样索引**,要么分块 + 稀疏 `Occ` 采样。
- `Occ` 全量表(每字符每位置)会爆炸;用**采样 + 局部扫 RLE**折中。
- `--pages-as-heap=yes` 连 mmap / 程序段都算,别想用 mmap 绕过。

### 3.2 重叠匹配 + 上下文边界
- `AA` 在 `AAA` 里算**两次**——backward search 天然按位置计数,区间大小就是次数。
- 匹配靠近序列开头/结尾时,前/后不足 2 个字符就**只输出可用的**。
- `\n` 是序列里的真实字符:上下文扫到 `\n` 该怎么算?(通常当作序列边界,
  **需在 CSE 上用 `dsearch` 对拍确认**是否跨行、是否输出 `\n`。)

### 3.3 输出格式
- 每个匹配一行,行尾 `\n`;**多一个字节的调试输出都会扣分**。
- 顺序无所谓(评测会 sort),但**行数必须 = 匹配数**(`wc -l` 对得上)。
